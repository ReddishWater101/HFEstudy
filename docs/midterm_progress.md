Problem Statement & Motivation
College students are often placed in fast-paced professional environments, such as career fairs, internships, and networking events, where they are expected to quickly learn and remember many names. We want to create an app to help with name recall, but found that mobile memory-support apps are often not designed in alignment with human cognitive limits, particularly for long-term memory encoding. From a human factors perspective, poorly designed interfaces can overload visual or auditory channels, fail to support effective encoding strategies, and overall reduce user performance. This project examines which specific app design features - specifically modality (visual vs auditory) and use of memory strategies (memory phrases) best support memory performance while reducing cognitive overload.

Approach and Study Design
The study uses a repeated-measures experimental design to evaluate how different interface features of a name-recall mobile application affect recall accuracy, response time, and perceived workload. The independent variables are modality with two levels (visual and auditory) and memory strategy with two levels(memory phrase and no memory phrase). These variables create four app conditions: visual with no memory phrase, visual with memory phrase, auditory with no memory phrase, and auditory with memory phrase. Participants will first complete a simulated social interaction scenario, in which they are introduced to 16 individuals, with one minute spent meeting each person. Afterwards, participants will use the mobile app to study the names of the 16 individuals in a specific manner. The app is designed in a flashcard style, and each participant will study four people under each of the four app modes. The four-name groupings will remain consistent across participants, and although names differ between modes, they will be matched for difficulty to ensure fair comparisons. For the memory phrase associated with each assigned person before beginning the study rounds, participants will rotate through all four modes for three rounds, spending 10 seconds on each card with short breaks between modes.
After the study phase, all participants will complete a filler task for approximately 5 to 10 minutes to reduce the influence of short-term memory. They will then return to a similar simulated scenario and attempt to recall the names of all 16 individuals within a set time limit. The same recall task will also be repeated 24 hrs later and again one week later to measure longer-term memory encoding and retention.
The dependent variables include the percentage of correctly recalled names, the response time for each naming attempt, and eye-tracking measures collected during app use. Cognitive workload and usability-related outcomes will be measured using post-task survey responses and the NASA Task Load Index, with emphasis on mental demand, effort, frustration, and temporal demand. The participant population will consist of college students, since they are the target users and the group most likely to encounter the real-world problem being studied. Overall, the study is designed to determine which app features produce the best balance of performance and workload, and to understand how app design and memory strategies interact to produce the best human performance.

Literature Review 
From our literature review, we read that face-name recall is cognitively demanding and relies on effortful associative memory. Studies in multimedia learning and multiple resource theory suggest that learning improves when visual and auditory information are used efficiently, with tools like NASA TLX provide reliable ways to measure perceived cognitive workload. Additionally, the generation effect demonstrates that actively generating information enhances memory compared to passive review. While these articles establish that modality and active engagement both influence memory and cognitive load, it does not directly test how these factors interact in a scenario like learning people’s names using an app interface. Our project fills this gap by combining modality (visual vs auditory) with memory strategies (memory phrases) in a simulated real-world context through an app interface, measuring performance and cognitive workload. Essentially, we are applying existing cognitive theories and strategies to app design, helping determine which feature combinations actually improve long-term name recall without overwhelming users.

Expected Outcomes 
We expect that participants using the auditory modality combined with a memory phrase strategy will demonstrate the highest recall accuracy, fastest response times, and lowest reported cognitive workload across all testing intervals. Participants using memory phrases are expected to outperform those without memory strategies due to deeper cognitive processing during encoding. Over time (24 hours and one week later), recall performance is expected to decline across all conditions, however, the auditory and memory condition should show the smallest decrease, indicating better long-term retention. NASA-TLX results should show lower mental demand in conditions that provide structured memory support, showing that the right app features can actually make remembering names feel less overwhelming.
