# Frontend
- UI: React + Tailwind CSS + shadcn/ui. Always use the frontend-design skill before any frontend work.
- Design ultra-minimal: no borders, dividers, or decorative elements unless functionally necessary. Favor whitespace, flat surfaces, and sparse layouts—every visual element must earn its place.
- Always extract reusable components and never duplicate UI logic.

# Rules
- Use subagents liberally for web searches, research, and repo exploration to avoid main context bloat.
